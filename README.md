# GTT - Grammar Checker Tools

![GTT Logo](gtt-logo.jpg)

A lightweight Chrome extension that checks English grammar and usage via Google Search.

## Usage

1. Select any text on a webpage
2. Right-click and choose "Ask Google to check grammar on this snippet"
3. Google Search opens with your text pre-prompted for grammar checking

## Installation

Load the extension in Chrome:
1. Open `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select this directory
